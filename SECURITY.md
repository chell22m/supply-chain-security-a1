# Security Policy

## Supported Versions

We actively monitor and patch vulnerabilities in the codebase. Security updates are applied strictly to the latest stable versions of the tool.

Current supported version: mc6440-assignment1

---

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security-related bugs or vulnerabilities.** 

We take the security of our cryptographic log verification tools seriously. If you discover a vulnerability please report it responsibly using one of the methods below:

### 1. GitHub Private Vulnerability Reporting (Preferred)
If you are viewing this repository on GitHub, navigate to the **Security** tab at the top of the repository page, click on **Vulnerability disclosure**, and select **Report a vulnerability**. 

### 2. Email Notification
Alternatively, you can email the maintainers privately at: **chell22m@mtholyok.edu**
